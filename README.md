# Markdown to HTML – Static Site Generator

A college project frontend for a simple Markdown-to-HTML static site generator. The current version is a **static webpage design** made with HTML5 and CSS3.

## Frontend completed so far

- A dark navy and charcoal theme with teal accents, soft borders, and rounded panels.
- A responsive navigation bar with the project name, Home, Docs, About, and a decorative theme icon.
- A hero section introducing the project, its features, and a CSS-only Markdown-to-webpage illustration.
- A Markdown editor panel with sample Markdown, static line numbers, a visible example menu, filename/status row, and a Convert to HTML button.
- An HTML preview panel with sample rendered headings, paragraph, list, link, desktop/mobile preview icons, and a sample HTML output card.
- A four-item feature strip describing Markdown conversion, static sites, no backend, and open source.
- Responsive layouts that place the editor and preview side by side on wider screens and stack them on mobile screens.

## Project files

- **`index.html`** contains the semantic page structure and sample content for the hero, editor, preview, and feature sections.
- **`style.css`** contains the color variables, page styling, CSS illustration, panel layouts, and tablet/mobile responsive rules.

## Current scope

This is a visual frontend prototype only. The menu, preview-size icons, Copy button, and Convert to HTML button are design elements; they do not perform actions. Markdown conversion, file upload, live preview, HTML file generation, JavaScript, and backend functionality have not been implemented.

## View the page

Open `index.html` in a web browser, or open the project folder in VS Code and use your preferred local preview method.
